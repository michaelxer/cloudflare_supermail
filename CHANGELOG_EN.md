## v1.0.0 (Initial Release)

### Features

- feat: |Core| Complete temporary email service powered by Cloudflare Workers
- feat: |Email| Unlimited disposable email address creation and receiving
- feat: |Email| Send email functionality (reply and compose new)
- feat: |Email| Email attachment receiving and download
- feat: |Email| Email export (JSON, CSV, EML formats)
- feat: |Email| Email search and filter (by sender, subject, date)
- feat: |Email| Auto-refresh inbox
- feat: |Telegram| Telegram Bot integration for email notifications
- feat: |Telegram| Global mail push (all emails notified)
- feat: |Telegram| Bulk bind addresses to Telegram
- feat: |Admin| Admin panel
- feat: |Admin| Bulk account creation (with fake name generator)
- feat: |Admin| Bulk management features
- feat: |Admin| Statistics dashboard
- feat: |Frontend| Responsive design (desktop and mobile)
- feat: |Frontend| Dark mode support
- feat: |Frontend| Multi-language support (6 languages)
- feat: |Security| JWT authentication
- feat: |Security| Admin password protection
- feat: |Storage| D1 database storage
- feat: |Storage| KV storage for configuration
- feat: |Storage| Email GZIP compression

### Configuration

- config: Custom domain support
- config: Custom title and copyright
- config: Multi-domain configuration
- config: Telegram Bot Token configuration
